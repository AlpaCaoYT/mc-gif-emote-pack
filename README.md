# 奶龙动图资源包生成器

把一个文件夹里的 **GIF 表情包** 一键转换成 Minecraft Java 版 **动态贴图资源包**（ZIP），游戏里的方块会变成会动的表情包。

## 功能

- 🎞️ GIF 自动转 MC 动画贴图：按每帧真实时长生成动画，速度和原表情一致，无残影
- 🧱 随机替换原版方块/物品贴图，可选范围：常见方块 / 全部方块 / 方块+物品
- 📦 自动生成 `pack.mcmeta`、`pack.png` 图标，直接打成 ZIP 即装即用
- 📋 生成替换报告 CSV，告诉你哪张表情替换了哪个方块
- 🎲 固定随机种子：同样素材每次生成结果一致，方便和朋友同步
- 🗜️ 分辨率可选 64 / 128 / 256，体积可控
- 🎮 支持 1.20 ~ 1.21.10 各版本 pack_format

## 使用方法

1. 安装 [Python 3](https://www.python.org/downloads/)（勾选 Add to PATH），然后安装图像库：
   ```
   pip install pillow
   ```
2. 双击 `资源包工具/启动生成器.bat`（或运行 `奶龙动图资源包生成器.py`）
3. 选好 GIF 素材文件夹 → 点「一键生成资源包」
4. 把输出的 ZIP 丢进 `.minecraft/resourcepacks`，游戏里启用即可

## 文件说明

| 文件 | 用途 |
|---|---|
| `资源包工具/奶龙动图资源包生成器.py` | 主程序（图形界面） |
| `资源包工具/启动生成器.bat` | 双击启动 |
| `资源包工具/vanilla_textures_1.21.10.json` | 原版贴图清单（自带，无需解包游戏） |

## 注意

- 动画贴图只对**方块/物品**生效，实体和 GUI 不支持（游戏机制限制）
