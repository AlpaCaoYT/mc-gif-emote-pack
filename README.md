# 动图资源包生成器

把一个文件夹里的 **GIF 表情包** 一键转换成 Minecraft Java 版 **动态贴图资源包**（ZIP），游戏里的方块会变成会动的表情包。

## 功能

- 🎞️ GIF 自动转 MC 动画贴图：按每帧真实时长生成动画，速度和原表情一致，无残影
- 🧱 随机替换原版方块/物品贴图，可选范围：常见方块 / 全部方块 / 方块+物品
- 📦 自动生成 `pack.mcmeta`、`pack.png` 图标，直接打成 ZIP 即装即用
- 📋 生成替换报告 CSV，告诉你哪张表情替换了哪个方块
- 🎲 固定随机种子：同样素材每次生成结果一致，方便和朋友同步
- 🗜️ 分辨率可选 64 / 128 / 256，体积可控
- 🎮 支持 1.20 ~ 1.21.10 各版本 pack_format
- 🖼️ 素材支持 GIF / 普通 PNG（静态贴图）/ WebP 动图
- 🚫 自定义排除规则：界面填方块/物品名（`*` 通配），跳过不想替换的贴图
- ♻️ 增量更新：勾选后沿用上次分配，只把新增表情加进去，几秒出包
- 🖥️ 生成后自动出「预览图.png」看表情分布，并产出「失败清单.txt」「替换报告.csv」
- ⏱️ 生成时显示进度与预计剩余时间

## 使用方法

1. 安装 [Python 3](https://www.python.org/downloads/)（勾选 Add to PATH），然后安装图像库：
   ```
   pip install pillow
   ```
2. 双击 `资源包工具/启动生成器.bat`（或运行 `动图资源包生成器.py`）
3. 选好 GIF 素材文件夹 → 点「一键生成资源包」
4. 把输出的 ZIP 丢进 `.minecraft/resourcepacks`，游戏里启用即可

## 文件说明

| 文件 | 用途 |
|---|---|
| `资源包工具/动图资源包生成器.py` | 主程序（图形界面） |
| `资源包工具/启动生成器.bat` | 双击启动 |
| `资源包工具/vanilla_textures_1.21.10.json` | 原版贴图清单（自带，无需解包游戏） |

输出文件夹（`输出/`）每次生成会多出几个文件：

| 文件 | 用途 |
|---|---|
| `你的资源包.zip` | 最终资源包，丢进 `.minecraft/resourcepacks` |
| `你的资源包_替换报告.csv` | 哪张表情替换了哪个方块/物品 |
| `你的资源包_失败清单.txt` | 生成失败的贴图清单（成功时不会出现） |
| `你的资源包_预览图.png` | 采样若干方块的表情缩略图（非游戏实拍） |
| `你的资源包_mapping.json` | 分配记录，**增量更新靠它复用上次结果，勿删** |

## 注意

- 动画贴图只对**方块/物品**生效，实体和 GUI 不支持（游戏机制限制）
- 草方块顶面、树叶、水、岩浆、时钟、指南针、刷怪蛋等会被游戏染色或有特殊机制的贴图已自动跳过，避免表情包变绿或显示异常
- 想额外跳过某些贴图（如钻石块、玻璃），在界面「自定义排除规则」填 `diamond_block,glass`（每行或逗号分隔，可用 `*` 通配）
- 增量更新：仅当你往素材文件夹**新增**表情、想在不打乱旧分配的前提下用上它们时勾选；普通重生成请用「全量」（不勾）
